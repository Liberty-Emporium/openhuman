# OpenHuman

Your Personal AI super intelligence. Private, Simple and extremely powerful.

## Overview

OpenHuman is a local AI harness that gives you a personal AI assistant running entirely on your machine. It combines local memory, managed services, and a simple interface to create a powerful AI experience that stays private.

## Features

- **Local Memory** — Persistent memory that stays on your machine
- **Managed Services** — Connect to external services when needed
- **Simple Interface** — Clean, straightforward interaction
- **Private** — Everything runs locally, no data leaves your machine

## Tech Stack

- **Language:** Rust
- **Platform:** Cross-platform (Linux, macOS, Windows)
- **Memory:** Local SQLite with vector search
- **Services:** Plugin-based service management

## Quick Start

```bash
# Clone and build
git clone https://github.com/Liberty-Emporium/openhuman.git
cd openhuman
cargo build --release

# Run
./target/release/openhuman
```
